# Cybersecurity Project – Week 2

This week, I completed the following cybersecurity activities using Kali Linux in VMware.

### PM1 – Footprinting
- Used WHOIS to collect domain information.
- Used WhatWeb to identify website technologies.
- Used NSLookup and DNSRecon for DNS information gathering.
- Used cURL to inspect HTTP headers.
- Used WAFW00F to check for Web Application Firewall protection.

### PM5 – Network Scanning
- Identified IP address and subnet using `ip addr` and `ip route`.
- Performed a Ping Scan using Nmap and Zenmap.
- Discovered 3 active hosts on the network.
- Examined available MAC address information.

### PM-FINAL – Project Report
- Prepared the final report documenting the objectives, tools, methodology, results, and conclusion.

### Learning Outcome
Gained practical knowledge of domain footprinting, network scanning, IP address identification, and basic cybersecurity reconnaissance.
